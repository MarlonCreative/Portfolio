# Portfolio

Marlon Fuentes's personal site: one hand-coded page in the Swiss International Style.

## What's in here

| File | What it does |
|---|---|
| `index.html` | The content and structure: every word on the page lives here, section by section. |
| `style.css` | The look: grid, type sizes, colours, the spinning record. Change the values in `:root` at the top to change the site globally. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is, without its Jekyll build step. |
| `CNAME` | (Added at launch.) Tells GitHub Pages which custom domain this site uses. |

## How to edit

1. Open `index.html` on github.com and click the pencil icon.
2. Change the text between the tags, e.g. `<p class="big">…</p>`.
3. Click **Commit changes**. The live site updates in about a minute.

## Design rules

- 12-column grid; labels sit in columns 1–3, content in 4–12.
- Two typefaces: Helvetica (Inter as fallback) and IBM Plex Mono.
- Three colours: ink `#111`, paper `#F5F3EF`, signal red `#E2231A`.
- The orbit in the hero: agents circling a red core; they speed up on hover.
